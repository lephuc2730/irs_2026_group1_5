# Industrial Robots and Systems – Group 5

This is our group project for Industrial Robots and Systems at the University of Canberra.

We are working on the Pine-Apple warehouse challenge. We use a PLC, ROS 2, navigation and a robotic arm to control a robot in the warehouse.

## Main parts

- `pa_warehouse_status` – PLC and ROS 2 communication
- `hand_solo_virtual_nav` – robot navigation
- `hand_solo_arm` – robotic arm movement
- `config` – system settings
- `scripts` – running and testing the project

## Progress

We have tested the robot navigation and arm movements. Picking up a real simulated box and putting it on the shelf still needs more testing.
